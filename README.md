## 🚀 Highlighted Engineering Projects

### 📞 Call Center AI — Multi-Tenant PBX Commercial Intelligence SaaS
> *Final-Year Engineering Project (PFE) • Monorepo (NestJS, Next.js, Go, PostgreSQL, GCP)*

* **Database-per-Company Isolation**: Designed multi-tenant architecture with isolated PostgreSQL databases per client alongside a centralized platform database.
* **On-Premise Go Connector**: Built a secure local Go binary communicating outbound via **mTLS** with a custom Certificate Authority to bridge client FreePBX/Asterisk calls without opening inbound ports.
* **LLM Pipeline & Benchmarking**: Integrated `gemini-3.5-flash` on Vertex AI for automated call transcription, sentiment analysis, objection extraction, and agent scoring with internal AI credit ledger billing.

### 🏥 HR Management Platform — Omnidoc Santé
> *Full Stack Web Application • Next.js, Supabase, Azure VM, Tailwind CSS*

* Implemented Role-Based Access Control (RBAC), multi-factor authentication, and responsive administrative dashboards for healthcare staff management.

### ⚡ CRM & Marketing Automation Ecosystem — Qualeads
> *Infrastructure, Funnels & Integration*

* Architected multi-channel conversion funnels, GoHighLevel workflows, Cloudflare DNS setups, Meta Pixel tracking, and Shopify webhooks for optimized client acquisition.
